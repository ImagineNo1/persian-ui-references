# Persian UI References

اسکیل طراحی رابط کاربری سایت‌های فارسی برای **Codex** و **Claude Code**؛ با انتخاب رفرنس مرتبط، طراحی راست‌به‌چپ، تایپوگرافی فارسی و انیمیشن سازگار با اتصال حروف.

این مخزن یک اسکیل مستقل مبتنی بر `SKILL.md` است؛ پلاگین یا کتابخانهٔ کامپوننت نیست. برای نصب به Git نیاز دارید. برای تحقیق زنده، عامل باید ابزار وب یا مرورگر داشته باشد؛ این اسکیل ابزار مرورگر یا سرویس پولی نصب نمی‌کند.

## منابع طراحی

| منبع | کاربرد |
| --- | --- |
| [Supahero](https://supahero.io/) | ترکیب‌بندی هیرو، سلسله‌مراتب و جای‌گذاری اقدام اصلی |
| [21st.dev](https://21st.dev/) | الگوهای UI، سکشن‌ها و کامپوننت‌های مرتبط |
| [Originkit](https://www.originkit.dev/) | تعامل، جلوه‌های بصری و حرکت |
| [Kawai Text Animation](https://kawai-text-animation.pages.dev/) | ایده‌های انیمیشن متن با تطبیق برای فارسی |
| [Fontshare](https://www.fontshare.com/) | جهت تایپوگرافی و فونت لاتین مکمل؛ با بررسی پشتیبانی فارسی |

لازم نیست در هر پروژه از هر پنج منبع چیزی استفاده شود. اسکیل تناسب رفرنس با موضوع، محتوا، موبایل و هویت فعلی پروژه را بررسی می‌کند و منابع انتخاب‌شده را با لینک گزارش می‌دهد. فونت‌های Fontshare خودبه‌خود مناسب فارسی فرض نمی‌شوند و افکت‌های حرف‌به‌حرف باید اتصال حروف فارسی را حفظ کنند.

## نصب در Codex

### Windows / PowerShell

```powershell
New-Item -ItemType Directory -Force -Path "$HOME/.agents/skills" | Out-Null
git clone https://github.com/ImagineNo1/persian-ui-references.git "$HOME/.agents/skills/persian-ui-references"
```

### macOS / Linux

```bash
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/ImagineNo1/persian-ui-references.git "$HOME/.agents/skills/persian-ui-references"
```

پس از نصب، اگر اسکیل در فهرست دیده نشد، Codex را دوباره باز کنید. برای فراخوانی:

```text
$persian-ui-references برای یک سایت فارسی خدمات معماری، رفرنس مرتبط پیدا کن و UI صفحات را در پروژه پیاده‌سازی کن.
```

پوشهٔ کاربری در این راهنما مطابق [مستندات رسمی مهارت‌های Codex](https://learn.chatgpt.com/docs/build-skills) انتخاب شده است. اگر قبلاً همین اسکیل را در مسیر دیگری مانند `~/.codex/skills` نصب کرده‌اید، نصب تکراری ایجاد نکنید. برای نصب فقط در یک پروژه، فایل‌های اسکیل را در `<project>/.agents/skills/persian-ui-references/` قرار دهید؛ `SKILL.md` باید مستقیماً داخل این پوشه باشد.

## نصب در Claude Code

### Windows / PowerShell

```powershell
New-Item -ItemType Directory -Force -Path "$HOME/.claude/skills" | Out-Null
git clone https://github.com/ImagineNo1/persian-ui-references.git "$HOME/.claude/skills/persian-ui-references"
```

### macOS / Linux

```bash
mkdir -p "$HOME/.claude/skills"
git clone https://github.com/ImagineNo1/persian-ui-references.git "$HOME/.claude/skills/persian-ui-references"
```

سپس Claude Code را باز کنید و بنویسید:

```text
/persian-ui-references برای یک فروشگاه فارسی، رفرنس مناسب انتخاب کن و صفحهٔ اصلی را با کامپوننت‌های موجود پروژه بساز.
```

مسیر نصب و فراخوانی مطابق [مستندات رسمی Claude Code](https://code.claude.com/docs/en/skills) است. برای استفاده فقط در یک پروژه، فایل‌های اسکیل را در `<project>/.claude/skills/persian-ui-references/` قرار دهید. این روش، نصب محلی در Claude Code است؛ نصب در حساب Claude.ai یا محیط ابری را انجام نمی‌دهد.

اگر مسیر مقصد از قبل وجود دارد، دستور `git clone` را تکرار نکنید. اگر آن پوشه با همین روش از همین مخزن کلون شده است، از دستور به‌روزرسانی زیر استفاده کنید؛ در غیر این صورت ابتدا محتوا و تغییرات محلی آن را بررسی کنید.

## خروجی اسکیل

- رفرنس‌های مرتبط با لینک، دلیل انتخاب و نحوهٔ تطبیق برای پروژه.
- جهت طراحی شامل ترکیب‌بندی، رنگ، فونت، فاصله‌ها و حرکت متناسب با نیاز.
- در درخواست پیاده‌سازی: کد UI در تکنولوژی موجود پروژه، با فارسی، RTL و چیدمان واکنش‌گرا.
- گزارش کوتاه از نتیجه، منابع و بررسی‌های انجام‌شده یا محدودیت دسترسی.

اگر فقط رفرنس بخواهید، کد پروژه تغییر نمی‌کند. فایل Figma، تصویر ماکاپ، فونت یا دارایی سایت‌های مرجع در این مخزن وجود ندارد و خودکار تولید نمی‌شود. این اسکیل دستورالعمل اجرایی برای عامل است؛ نتیجهٔ طراحی به زمینهٔ پروژه و ابزارهای در دسترس آن وابسته است.

## نمونهٔ درخواست

برای دریافت فقط پیشنهاد طراحی، بعد از نام اسکیل بنویسید:

```text
برای سایت فارسی رزرو اقامتگاه، فقط رفرنس و جهت طراحی پیشنهاد بده؛ فعلاً کد را تغییر نده. مخاطب خانواده‌ها هستند و حس بصری باید آرام و قابل‌اعتماد باشد.
```

برای کار روی پروژهٔ موجود:

```text
صفحهٔ اصلی این پروژه را با استفاده از رفرنس‌های مرتبط بازطراحی کن. فونت و توکن‌های فعلی را حفظ کن، راست‌به‌چپ و موبایل را بررسی کن و انیمیشن را فقط در صورت نیاز اضافه کن.
```

قوانین و تأییدهای لازم پروژه، از جمله `AGENTS.md` یا `CLAUDE.md`، همچنان اعمال می‌شوند.

## به‌روزرسانی

برای نصب کاربری Codex:

```bash
git -C "$HOME/.agents/skills/persian-ui-references" pull --ff-only
```

برای نصب کاربری Claude Code:

```bash
git -C "$HOME/.claude/skills/persian-ui-references" pull --ff-only
```

این دو دستور در PowerShell نیز قابل اجرا هستند. اگر فایل‌های اسکیل را محلی تغییر داده‌اید، پیش از به‌روزرسانی تغییرات را بررسی کنید؛ از بازنشانی اجباری استفاده نکنید.

## ساختار

```text
persian-ui-references/
├── SKILL.md                    # دستورالعمل مشترک برای هر دو عامل
├── agents/openai.yaml          # اطلاعات نمایشی Codex
├── references/source-guide.md  # راهنمای منابع و محدودیت‌های شناخته‌شده
└── README.md                   # نصب و استفاده
```

این پروژه وابستگی اجرایی، اسکریپت نصب یا MCP اجباری ندارد. مجوز کد، تصویر و فونت هر مرجع باید پیش از استفادهٔ مستقیم جداگانه بررسی شود؛ معرفی یک سایت به معنی مجوز بازنشر دارایی‌های آن نیست.
